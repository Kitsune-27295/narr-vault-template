# Session Journal

Append-only record of working sessions: `- [YYYY-MM-DD] <kind> | <what changed and why it mattered>`.
Create one file per month (`YYYY-MM.md`); `npm run session:close` appends to the current month.

- [2026-11-02] architecture | Template instantiated from the Narrative Vault Framework.
