# Scope Profiles

## Epistemic Scope Hierarchy
1. `source_canon`: Absolute unalterable baseline established by original source works.
2. `fanfic_canon`: The unified shared reality of this fanfic story bible.
3. `au_alternate`: What-if alternate branches exploring divergent timelines.
4. `au_divergence`: A deliberate point-of-divergence branch that can also see `fanfic_canon`.
5. `sandbox`: Unverified brainstorming and ideation notes. Never used in canon context.
6. `meta`: Operational pages (ledgers, memory, curator context) that belong to no story timeline.

Who can see whom is configured in `vault.yaml` under `scopes.hierarchy`; this list must name exactly those scopes plus `meta`.
