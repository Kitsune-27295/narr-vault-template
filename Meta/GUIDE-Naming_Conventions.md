# Naming Conventions & Disambiguation Guide

## 1. Zero-Space Filename Rule
All markdown filenames must use underscores and never spaces:
- Correct: `CHR-Tang_San.md`
- Incorrect: `CHR-Tang San.md`

## 2. Disambiguation
When multiple versions of an entity exist:
- `CHR-Tang_San_(Canon)` vs `CHR-Tang_San_(AU)`

## 3. Localization Transliteration
Always use Pinyin or established English translations outside raw frozen sources. Never place raw CJK characters in file names or non-source headers.
