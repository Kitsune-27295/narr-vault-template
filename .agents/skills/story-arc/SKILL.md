# story-arc

Use this skill to plan or restructure a narrative arc in `03_Continuity_and_Timeline/Arcs/`.

## Workflow
1. Scaffold arc via `narr new arc "<Arc Title>"`.
2. Define Want vs Need dramatic spine.
3. Map beat sheet (Inciting Incident → Midpoint → Dark Night → Climax).
4. Link active plot threads in `08_Ledgers/LDG-Active_Threads.md`.
5. Run `narr graph` to confirm connectivity.
