# Rule 15: Non-Manuscript Technical Writing Style
1. **Clarity & Simplicity:** Use direct, natural language without superfluous pedantry or empty filler.
2. **Objectivity:** Limit each sentence to one primary idea.
3. **Active Voice Mandate:** Always write in active voice ("Faction X controls the route" instead of "The route is controlled by Faction X").
4. **Short Sentences & Paragraphs:** Sentences under 30 words; paragraphs of 2 to 4 sentences. Favor bullet points and markdown tables for relational data.
5. **Zero AI Preambles:** Never begin documents with conversational chatter ("Here is...", "Certamente!"). Start immediately with the title, note, or frontmatter.
6. **Visual Hierarchy:** Exactly one `# Title` per page. Use structured subheadings (`##`, `###`) and semantic bolding for key terms.
7. **Mermaid Diagram Mandate (Zero ASCII Art - VAL009):** Never draw diagrams using text boxes, `+--`, or ASCII art. Always use native Mermaid (````mermaid`) fenced code blocks with double-quoted node labels (`node["Label"]`) and semantic diagram types (flowchart, timeline, stateDiagram-v2).
