# Rule 20: Manuscript & Localization Governance
1. **Language Roles:**
   - Drafts are authored in `pt-BR` (`04_Manuscript/pt-BR/Chapters/`).
   - Publication prose is translated into `es` (`04_Manuscript/es/Chapters/`).
2. **Termbase Compliance:** Every translated technique, item, rank, and formal address must adhere strictly to `02_Story_Bible/Terminology/TRM-Termbase.md`.
3. **No Prose Overwrite:** The agent must never rewrite or overwrite manuscript prose without explicit curator instruction.
