# Rule 10: Note Conventions & Taxonomy
1. **Zero-Space Filenames:** Filenames must NEVER contain whitespace. Use underscores (`CHR-Tang_San.md`).
2. **Flat Bidirectional Topology:** Place entities directly in their zone roots. Link entities via `[[Page_Name]]` rather than deep nested directory trees.
3. **No CJK Characters:** Outside `01_Canon_and_Divergence/Sources/`, never use raw CJK characters. Use Pinyin or English transliteration.
4. **Strict Canonical Prefixes:** `SRC-` (Sources), `CAN-` (Baselines), `POD-` (Divergence), `CHR-` (Characters), `LOC-` (Locations), `FAC-` (Factions), `SYS-` (Systems), `PWR-` (Powers), `TEC-` (Techniques), `SET-` (Settei), `EVT-` (Events), `ARC-` (Arcs), `LDG-` (Ledgers).
