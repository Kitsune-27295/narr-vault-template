# Rule 00: This is a Vault
1. This repository is an LLM Wiki and Operational Narrative Vault maintained by agents and governed by the `narr` CLI.
2. The curator owns the story vision, decisions, and creative approvals. The agent compiles the encyclopedia, maintains continuity ledgers, and drafts according to strict contracts.
3. Every operational command must be verified with `narr lint` (exit code 0).
